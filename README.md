# C-EPT 第四級 自學複習站

純靜態網站（無需安裝任何東西）。用瀏覽器開啟 `index.html` 即可使用；進度存在瀏覽器的 localStorage。

## 功能
- **單字卡**：四級單字 1,502 個詞條（學會 113 年版），盒子制複習、發音、例句
- **單字測驗**：英→中、中→英、例句填空、拼字、混合
- **歷屆題**：第 27–31 屆第四級非聽力題（第 21–60 題，共 200 題）含解析與文章中譯，支援練習／模擬模式
- **錯題本**：自動收錄，重做答對後移出
- **考試資源**：官方下載連結、常考文法重點

聽力（第 1–20 題）需要音檔與圖片，請至學會官網下載：https://www.cves.org.tw/download-eng

## 資料來源與更新
單字與試題來自中華民國商業職業教育學會公開提供的下載檔，著作權屬該學會，僅供個人學習使用。
`data.js` 由官方 PDF 解析產生；第 28 屆第 51–55 題的圖片題以頁面截圖呈現（`img/28-51.jpg`）。
